# 03. 화면 구현 지침 (UI 구현 지침 ②)

> 화면마다 **무엇이, 어떤 순서로, 어떤 컴포넌트로** 놓이는지 정합니다. 색·크기 값은 `02-design-system.md` 의 토큰 이름으로만 적습니다.
> 그림(와이어프레임)은 배치만 나타냅니다. 실제 모양은 디자인 시스템을 따릅니다.

---

## 1. 공통 틀 (모든 화면)

```
┌──────────────────────────────────────────────────────────────┐
│ 유틸리티 스트립 (ink, 36px)                                    │
│ 전력시장 디지털 인재 아카데미            기록 12 / 40일 · 설정 │
├──────────────────────────────────────────────────────────────┤
│ 상단 내비게이션 (canvas, 64px, 아래 1px hairline)              │
│ ▰▰ 요약.zip   날짜별  분야별          [🔍 기록 검색   ] [오늘 기록]│
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  <main> 화면별 내용                                           │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ 다크 푸터 (ink)                                               │
└──────────────────────────────────────────────────────────────┘
```

### 1.1 유틸리티 스트립 (`header.js`)
| 위치 | 내용 | 규칙 |
|---|---|---|
| 왼쪽 | 과정 이름 (`course.name`) | `caption-md`, on-ink, 한 줄 말줄임 |
| 오른쪽 | `기록 {작성한 날 수} / {전체 날짜 섹션 수}일` · `설정` 링크 | 모바일(<768px)에서는 숫자 숨기고 설정 아이콘(44×44)만 |

"작성한 날" = `learned` 또는 `reflection` 이 1자 이상이거나 메모지가 1장 이상인 Day.

### 1.2 상단 내비게이션
| 위치 | 데스크톱(≥1024px) | 태블릿·모바일(<1024px) |
|---|---|---|
| 왼쪽 | 로고 `요약.zip` (→ `#/`) | 로고 |
| 가운데 | 메뉴 링크 `날짜별`(`#/`), `분야별`(`#/fields`) — `body-md`, 여백 8px 16px, 현재 화면 링크는 아래 2px primary 밑줄 + `aria-current="page"` | 숨김 |
| 오른쪽 | 검색창(폭 240px, 높이 40px, 모서리 4px, 오른쪽에 돋보기 아이콘) + `오늘 기록` 버튼(`.btn--outline-ink`) | 검색 아이콘 버튼 + 햄버거 아이콘 버튼 |

- 검색창에서 Enter → `#/search?q={입력값}` 이동. 빈 값이면 이동하지 않음.
- 모바일 검색 아이콘 → 내비게이션 바로 아래에 검색 입력 줄이 펼쳐짐(높이 56px, 자동 포커스, Esc로 닫힘).
- 햄버거 → 오른쪽에서 전체 화면 시트(배경 canvas, 그림자 float). 내용: 닫기 버튼, 링크 목록(`날짜별`, `분야별`, `설정`; `body-lg`, 각 줄 높이 56px), 맨 아래 고정 `오늘 기록 쓰기`(`.btn--ink`, 폭 100%). 열려 있는 동안 뒤 스크롤 잠금, Esc·바깥 클릭·링크 클릭 시 닫힘, 포커스는 시트 안에 가둠.

### 1.3 다크 푸터 (`footer.js`)
- 배경 ink, 글자 on-ink, 안쪽 여백 64px 위아래(모바일 48px).
- 3열(데스크톱) → 1열(모바일):
  1. 로고(흰색 버전: 글자 on-ink, 점과 쉐브론은 primary-bright) + "전력시장 디지털 인재 아카데미 학습 기록" `caption-md`
  2. 바로가기: 날짜별 / 분야별 / 설정 (`caption-md` 링크)
  3. 데이터 안내: "기록은 이 브라우저에만 저장돼요. 가끔 백업해 주세요." + `백업 파일 내보내기` 텍스트 버튼(primary-bright)
- 맨 아래 1px ink-soft 구분선 + `© 2026 요약.zip · 개인 학습 기록용` (`caption-sm`, steel 색).

### 1.4 화면 이동 시 공통 동작
- 화면이 바뀌면 `window.scrollTo(0, 0)` 후 `<main>` 에 포커스(스크린리더 안내용), `document.title` 을 `{화면 제목} — 요약.zip` 으로 바꾼다.
- 데이터를 읽는 동안 `<main>` 에 "불러오는 중…"(`caption-md`, graphite) 표시. 200ms 안에 끝나면 표시하지 않는다.

### 2.1 히어로
| 요소 | 명세 |
|---|---|
| 카드 | 배경 cloud, 모서리 16px, 안쪽 여백 32px(모바일 24px). 데스크톱: 왼쪽 글(60%) + 오른쪽 통계(40%) 2열. 모바일: 1열(글 → 통계) |
| 쉐브론 | 카드 왼쪽 바깥·오른쪽 바깥에 각 2개 (`02 §6.6`) |
| 눈썹 글 | 과정 이름, `caption-bold`, graphite |
| 제목 | `오늘 배운 것을` 줄바꿈 `요약.zip에 담아요` — `display-lg`(모바일 `display-md`), ink |
| 기간 | `YYYY.MM.DD – YYYY.MM.DD · N일` `body-md` charcoal. 과정 기간이 없으면 "과정 기간을 설정해 주세요" + 설정 링크 |
| 버튼 | `오늘 기록 쓰기` (`.btn--primary`) + `분야별로 보기` (`.btn--outline-ink`). 모바일은 세로로 쌓고 폭 100% |
| 통계 4칸 | 2×2 그리드, 각 칸: 배경 paper, 모서리 8px, 여백 16px. 숫자 `stat-md` + 라벨 `caption-md` graphite. 항목: `기록한 날`(N일), `성장 메모지`(N장), `분야`(N개), `팀플`(N개) |

### 2.2 필터
- 상태 탭 3개: `전체`(기본) / `작성한 날` / `빈 날` — `.tab`. 한 번에 1개 선택.
- 분야 칩 줄: 모든 분야를 `Field.order` 순으로 `.chip` 표시. 여러 개 선택 가능 → **선택한 분야 중 하나라도** 붙은 날만 표시(OR). 다시 누르면 해제. 모바일에서는 가로 스크롤(줄바꿈 없음).
- 분야가 0개면 분야 칩 줄 대신 "분야를 만들면 여기서 골라 볼 수 있어요 → 분야 만들기" 링크.
- 필터 상태는 주소에 저장: `#/?status=written&fields=id1,id2` (새로고침해도 유지).
- 오른쪽 `+ 날짜 추가` (`.btn--outline-ink .btn--sm`) → 날짜 추가 모달(`05 §2.3`).

### 2.3 주차 그룹
- 그룹 머리: `{N}주차` (`display-sm`) + `MM.DD – MM.DD · {날 수}일 중 {작성 수}일 작성` (`caption-md`, graphite). 그룹 사이 1px hairline + 위아래 32px.
- 그룹 안 카드 그리드: 1 / 2 / 3 / 4 열 (`02 §4.5`), 간격 `--gutter`.
- 필터 결과 날짜가 0개인 주차는 그룹째 숨긴다. 전체 결과가 0개면 빈 상태: fog 배경 박스(모서리 16px, 여백 48px, 가운데 정렬) "조건에 맞는 날짜가 없어요" + `필터 초기화` 버튼.
- 날짜 섹션이 아예 0개면: "아직 날짜 섹션이 없어요" + `과정 기간 설정`(.btn--ink, → `#/settings`) + `날짜 추가`(.btn--outline-ink) 버튼.

### 2.4 날짜 카드 (`dayCard.js`)
```
┌─────────────────────────────┐
│ [12일차] [TODAY]     작성함 │  ← 배지들 + 상태(caption-md)
│ 11월 23일 (월)              │  ← display-xs
│ SMP 결정 원리와 전력거래소  │  ← 제목 body-emphasis, 1줄 말줄임
│ 계통한계가격은 시간대별로…  │  ← 배운 내용 미리보기 caption-md charcoal, 2줄 말줄임
│ ●전력시장 기초 ●팀플-수요 +1│  ← 분야 칩(작게, 최대 2개 + "+N")
│ 💡 3   📎 2                 │  ← 아이콘(bulb, file) + 숫자 caption-md graphite
└─────────────────────────────┘
```
- 카드 전체가 하나의 링크 `<a class="card day-card" href="#/day/2026-11-23">`. 안에 다른 버튼을 넣지 않는다.
- 오늘 카드: `TODAY` 배지(.badge) 앞에 6px bloom-coral 점. 카드 테두리 2px ink.
- 빈 카드(작성 안 함): 배경 cloud, 그림자 없음, 미리보기 자리에 "아직 기록이 없어요"(graphite). 상태 글자 `비어 있음`.
- 제목이 없으면 제목 줄을 생략(빈 줄 남기지 않음).
- 📎 숫자 = 그날 모든 팀플 일지의 첨부 수 합. 0이면 숨김. 💡 숫자 = 메모지 수. 0이면 숨김. (그림의 이모지는 설명용, 실제로는 SVG 아이콘)
- 스크린리더용 `aria-label`: `"12일차, 11월 23일 월요일, 작성함, 메모지 3장"`.

### 3.1 화면 머리
- 본문 폭 `--content-max`(880px), 가운데 정렬.
- 첫 줄: 왼쪽 브레드크럼(`날짜별` 링크 › `{N}주차`), 오른쪽 이전/다음 날짜 섹션 이동(`.icon-btn` + `MM.DD`). 처음/마지막이면 해당 버튼 비활성.
- 눈썹: `{N}일차 · {N}주차` `caption-bold` graphite.
- 제목: `M월 D일 요일` (`display-md`) + 오늘이면 TODAY 배지.
- 오른쪽: 저장 상태 (`caption-md`): `저장 중…` / `저장됨 HH:MM` (graphite) / `저장 실패 — 다시 시도` (bloom-deep, 누르면 재저장). `aria-live="polite"`.
- 주소의 날짜 섹션이 없으면: "11월 23일 날짜 섹션이 없어요" + `이 날짜 만들기`(.btn--ink) + `홈으로`.

### 3.2 섹션 A — 오늘의 기록
- `.card--feature`(cloud 배경) 안에 라벨+입력창 3개. 순서: 제목 → 배운 내용 → 느낀 점.
- placeholder: 제목 `예) SMP 결정 원리와 전력거래소 역할`, 배운 내용 `오늘 배운 핵심 개념, 예시, 실습 내용을 정리해요`, 느낀 점 `어려웠던 점, 새로 알게 된 점, 소감을 적어요`.
- 각 입력창 아래 글자 수 `0/5000`.

### 3.3 섹션 B — 성장 기록 메모지 (섹션 A **바로 아래**)
- 제목 `성장 기록 메모지` (`display-sm`) + 개수 `(5/30)` + 설명 1줄 (`caption-md`).
- 그리드: 1열(<480) / 2열(480–1023) / 3열(≥1024), 간격 24px. 마지막 칸은 항상 `+ 메모지 추가` 점선 칸(30장이면 숨기고 "메모지는 하루 30장까지예요" 안내).
- 메모지 보기 상태: `02 §6.5`. 메모지 전체를 클릭/Enter 하면 편집 상태로.
- 메모지 편집 상태(같은 자리에서 바뀜):
  - 종류 선택: 라디오 3개를 버튼처럼(`관심` `궁금` `다짐`)
  - 색 선택: 원형 스와치 4개(24px, 선택된 것은 2px ink 테두리, `aria-label="파랑"` 등)
  - 내용 textarea(자동 포커스, 300자, 글자 수 표시)
  - `저장`(.btn--ink .btn--sm), `취소`(.btn--outline-ink .btn--sm). Ctrl/⌘+Enter = 저장, Esc = 취소.
- 새 메모지: `+ 메모지 추가` → 그 자리에 빈 편집 상태 메모지 생성(기본 색 blue, 종류 관심). 내용이 빈 채로 저장하면 "내용을 입력해 주세요".

### 3.4 섹션 C — 분야 태그
- 제목 `분야 태그` (`display-sm`) + 오른쪽 `AI 추천`(.btn--outline-ink .btn--sm, sparkle 아이콘) + `+ 새 분야`(.btn--text).
- 모든 분야를 `.chip` 토글로 표시(`aria-pressed`). 팀플 분야 칩에는 이름 뒤 작은 users 아이콘.
- AI 추천 결과: 칩 줄 아래 primary-soft 배경 박스(모서리 8px, 여백 12px 16px): "AI 추천: ●전력시장 기초 ●머신러닝" + 각 칩 옆 `붙이기` 텍스트 버튼 + `모두 붙이기` + 닫기. 이미 붙은 분야는 추천에서 제외.
- 분야가 0개: "아직 분야가 없어요" + `+ 새 분야` 버튼.

### 3.5 섹션 D — AI 하루 요약 (`aiPanel.js`)
| 상태 | 표시 |
|---|---|
| 결과 없음 | 설명 "배운 내용·느낀 점·메모지를 3줄로 요약해요" + `AI 하루 요약 만들기` (**.btn--primary — 이 화면의 유일한 주요 버튼**) |

### 3.6 섹션 E — 팀플 일지 (`teamLogCard.js`, `attachmentList.js`)
- 분야 태그 중 팀플 분야마다 카드 1개(분야 순서대로). 팀플 태그가 없으면 섹션 전체를 그리지 않는다.

  - 그 외 파일: file 아이콘 / 링크: link 아이콘

  - 오른쪽: 이름 영역 클릭 = 열기, `✕` 아이콘 버튼(`aria-label="{이름} 삭제"`) = 삭제 확인
- 업로드 줄: `파일 추가`(.btn--outline-ink .btn--sm, upload 아이콘) / `링크 추가`(.btn--outline-ink .btn--sm, link 아이콘) + 안내 `또는 파일을 여기로 끌어다 놓으세요`(caption-sm, 모바일에서는 숨김).
