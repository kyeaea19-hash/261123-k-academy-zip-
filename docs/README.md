## 비전공자를 위한 용어 사전

| 용어 | 쉬운 설명 |
|---|---|
| 프론트엔드 (Front-End) | 브라우저 화면에 보이는 부분. HTML(뼈대) + CSS(옷) + JS(움직임) |
| 백엔드 (Back-End) | 화면 뒤에서 일하는 서버. 여기서는 "OpenAI에 대신 물어봐 주는 심부름꾼" 역할만 한다 |
| Node.js | 자바스크립트를 브라우저 밖(컴퓨터·서버)에서 실행하게 해 주는 프로그램 |
| npm | Node.js용 부품(패키지) 설치 도구. `npm install` = 필요한 부품 받기 |
| API | 프로그램끼리 대화하는 창구. "이 주소로 이런 형식으로 보내면 이렇게 답해 줄게"라는 약속 |
| OpenAI API 키 | OpenAI를 쓰기 위한 비밀번호. 유출되면 남이 내 돈으로 AI를 쓸 수 있다 |
| 환경변수 | 코드 밖에 따로 보관하는 설정값·비밀값. 코드에 비밀번호를 적지 않으려고 쓴다 |
| Vercel | 만든 웹사이트를 인터넷에 올려 주는 서비스. GitHub와 연결하면 자동 배포 |
| Serverless Function | 요청이 올 때만 잠깐 켜지는 작은 서버 코드. `api/` 폴더의 파일 1개 = 주소 1개 |
| IndexedDB | 브라우저 안에 있는 저장 창고. 파일(이미지·PDF)까지 넣을 수 있다. 브라우저 데이터를 지우면 함께 지워진다 |
| localStorage | 브라우저의 작은 메모장. 간단한 설정값만 넣는다 |
| 해시 라우팅 | 주소 뒤 `#/day/2026-11-23` 처럼 `#` 뒤를 바꿔 페이지를 이동하는 방식. 서버 설정 없이 동작 |
| 컴포넌트 | 화면 부품. 예: 날짜 카드, 메모지, 버튼 |
| 디자인 토큰 | 색·크기 등을 이름 붙여 저장한 값. 예: `--color-primary` = 파란색 |
| 웹폰트 | 인터넷에서 내려받아 쓰는 글꼴. 사용자 컴퓨터에 설치되어 있지 않아도 된다 |
| 디바운스 (debounce) | "입력이 멈추고 0.8초 지나면 한 번만 저장" 처럼 너무 자주 실행되지 않게 하는 기법 |
| 토스트 | 화면 아래에 잠깐 떴다 사라지는 알림 |
| 모달 | 화면 위에 뜨는 대화상자 창 |
| JSON | 데이터를 글자로 적는 표준 형식. `{ "이름": "값" }` |
| Structured Outputs | OpenAI가 정해 준 JSON 모양대로만 답하도록 강제하는 기능 |
| 반응형 | 화면 폭(휴대폰·태블릿·PC)에 맞춰 배치가 바뀌는 것 |
